# Devkits — macOS 原生开发者工具箱（Vibe Coding）

一套纯原生（Swift + SwiftUI）的 macOS 开发者工具集。单窗口、侧边栏切换、离线可用，无任何第三方运行时依赖，安装即用。

## 下载

前往 [Releases](../../releases) 页面下载最新的 `Devkits.dmg`：

1. 打开 DMG，将 `Devkits.app` 拖入「应用程序」文件夹
2. 首次启动如提示无法验证开发者，请前往 **系统设置 → 隐私与安全性**，点击「仍要打开」

系统要求：macOS 14+

## 功能一览

| 工具 | 说明 |
|------|------|
| JSON 工具 | 格式化 / 压缩 / 校验，重复 key 标红与悬浮提示，节点折叠，JSON Pointer 跳转 |
| 文本对比 | 双栏 diff，行内词级高亮，错位 hunk 连接带 |
| Base64 编解码 | 文本与 Base64 互转 |
| YAML ↔ JSON | 双向转换 |
| 正则测试 | 实时匹配、分组捕获展示 |
| HTTP 请求 | 构造并发送请求，查看响应 |
| JWT 解码 | Header / Payload / 签名结构解析 |
| 哈希计算 | MD5 / SHA1 / SHA256 等 |
| URL 编解码 | 百分号编解码 |
| 时间戳转换 | Unix 时间戳与日期互转 |
| 进制转换 | 2/8/10/16 进制 |
| UUID 生成器 | 批量生成 UUID |
| Cron 解析 | Cron 表达式解析与下次执行时间 |
| 颜色工具 | 颜色格式转换与预览 |
| 格式命名转换 | camelCase / snake_case / kebab-case 等互转 |
| 文本小工具 | 行去重、排序、trim 等常用文本处理 |

所有含文本编辑器的工具均内置统一编辑器：语法高亮、行号标尺、自动换行开关、JSON 折叠，以及 `⌘F` 查找（支持正则与大小写敏感，`⌘G` / `⇧⌘G` 前后导航）。
